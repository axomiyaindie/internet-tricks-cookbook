# GitHub Shortcuts and URL Tricks

**Purpose:** Navigate GitHub faster using keyboard shortcuts and URL changes.
**Requirements:** A browser.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `?` | Show all shortcuts for the current page |
| `t` | Open the file finder in a repository |
| `.` | Open the repository in the web editor |
| `y` | Turn the URL into a permanent link to the exact commit |
| `b` | Open blame view on a file |
| `l` | Jump to a line |
| `w` | Switch branch or tag |
| `g` then `i` / `p` | Go to Issues / Pull requests |
| `/` | Focus the search box |

## URL tricks

| Add to the URL | Result |
|---|---|
| `github.dev` instead of `github.com` | Opens the web editor |
| `.patch` or `.diff` after a pull request URL | Raw patch or diff |
| `/username.keys` after `github.com` | Public SSH keys of that user |
| `/username.png` after `github.com` | The user's avatar image |
