# DevTools Shortcuts and Commands

**Purpose:** Use Chrome and Edge DevTools shortcuts and the command menu to work faster.
**Requirements:** Chrome or Edge on Windows or Linux. On Mac, use `Cmd`.

## Shortcuts

| Shortcut | Action |
|---|---|
| `F12` or `Ctrl` + `Shift` + `I` | Open DevTools |
| `Ctrl` + `Shift` + `C` | Inspect an element |
| `Ctrl` + `Shift` + `J` | Open the Console |
| `Ctrl` + `Shift` + `M` | Toggle the device toolbar |
| `Ctrl` + `Shift` + `P` | Open the command menu |
| `Ctrl` + `P` | Open a file by name |
| `Ctrl` + `Shift` + `F` | Search across all loaded files |

## Command menu tricks

Press `Ctrl` + `Shift` + `P`, then type:

- `Capture full size screenshot` for a screenshot of the whole page.
- `Capture node screenshot` for the selected element.
- `Disable JavaScript` to test without scripts.
- `Show Rendering` to emulate dark mode or reduced motion.

## Network tab

- Right-click a request > **Copy** > **Copy as cURL** to repeat it in a terminal.
- Tick **Disable cache** and **Preserve log** while debugging.

## Local overrides

Sources > **Overrides** lets you edit a file and keep your changes after reload, for testing.
