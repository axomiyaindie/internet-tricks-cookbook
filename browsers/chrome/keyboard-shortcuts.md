# Chrome Keyboard Shortcuts

**Purpose:** Navigate Chrome faster with the shortcuts that save the most time.
**Requirements:** Chrome or Edge on Windows or Linux. On Mac, use `Cmd` instead of `Ctrl`.

| Shortcut | Action |
|---|---|
| `Ctrl` + `T` | New tab |
| `Ctrl` + `Shift` + `T` | Reopen the last closed tab |
| `Ctrl` + `W` | Close the tab |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Next or previous tab |
| `Ctrl` + `1` to `8` | Jump to that tab. `Ctrl` + `9` goes to the last tab |
| `Ctrl` + `L` | Focus the address bar |
| `Ctrl` + `Shift` + `A` | Search open tabs (Chrome) |
| `Ctrl` + `Shift` + `N` | Incognito window |
| `Ctrl` + `D` | Bookmark the page |
| `Ctrl` + `Shift` + `B` | Show or hide the bookmarks bar |
| `Ctrl` + `H` / `Ctrl` + `J` | History / Downloads |
| `Ctrl` + `Shift` + `Delete` | Clear browsing data |
| `Ctrl` + `Shift` + `V` | Paste as plain text |
| `Ctrl` + `F` | Find on page |
| `Ctrl` + `+` / `-` / `0` | Zoom in, out, reset |
| `Alt` + `Left` / `Right` | Back or forward |
| `Ctrl` + `U` | View page source |
| `F12` | Open DevTools |
