# Search Engine Quick Answers

**Purpose:** Get instant answers by typing a simple phrase into search.
**Requirements:** Google. Many also work in Bing and DuckDuckGo.

| Type this | You get |
|---|---|
| `10 usd to inr` | Currency conversion |
| `5 km in miles` | Unit conversion |
| `2^10 + 5*3` | A calculator |
| `timer 10 minutes` | A countdown timer |
| `stopwatch` | A stopwatch |
| `time in tokyo` | Current time in a city |
| `weather` | Local forecast |
| `define serendipity` | Dictionary definition |
| `translate hello to spanish` | Translation |
| `flip a coin` or `roll a die` | Random result |
| `random number` | A random number generator |
| `my ip` | Your public IP address |
