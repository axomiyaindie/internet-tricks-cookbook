# Firefox about: Pages

**Purpose:** Use Firefox's built-in diagnostic and settings pages.
**Requirements:** Firefox. Type each address into the address bar.

| Address | What it does |
|---|---|
| `about:config` | Advanced preferences (accept the warning first) |
| `about:processes` | Task manager showing which tabs use CPU and memory |
| `about:addons` | Manage extensions, themes, and plugins |
| `about:preferences` | Main settings page |
| `about:logins` | View and manage saved passwords |
| `about:downloads` | Download history |
| `about:support` | Troubleshooting information and the Refresh Firefox option |

## Safe mode

Hold `Shift` while starting Firefox, or use `about:support` > **Restart with Add-ons Disabled**, to check whether an extension causes a problem.
