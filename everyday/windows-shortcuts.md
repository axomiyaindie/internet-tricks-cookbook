# Windows Shortcuts

**Purpose:** Use Windows shortcuts that save time every day.
**Requirements:** Windows 10 or 11.

| Shortcut | Action |
|---|---|
| `Win` + `V` | Clipboard history (turn it on the first time) |
| `Win` + `Shift` + `S` | Screenshot a region |
| `Win` + `.` | Emoji, symbols, and GIF picker |
| `Win` + `Left` / `Right` | Snap a window to a side |
| `Win` + `Shift` + `Left` / `Right` | Move a window to another monitor |
| `Win` + `Ctrl` + `D` | New virtual desktop |
| `Win` + `Ctrl` + `Left` / `Right` | Switch virtual desktops |
| `Win` + `Tab` | Task view |
| `Win` + `E` | File Explorer |
| `Win` + `D` | Show the desktop |
| `Win` + `L` | Lock the computer |
| `Win` + `X` | Power user menu |
| `Win` + `I` | Settings |
| `Ctrl` + `Shift` + `Esc` | Task Manager |
