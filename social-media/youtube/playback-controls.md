# YouTube Playback Controls

**Purpose:** Use hidden player options for speed, looping, timestamps, and diagnostics.
**Requirements:** YouTube in a desktop browser. Some options also exist in the app.

## Custom playback speed

1. Click the gear icon in the player.
2. Choose **Playback speed**, then **Custom** to pick any speed between 0.25x and 2x.

## Right-click menu

Right-click the video (twice if the browser menu appears) for:

- **Loop** to repeat the video.
- **Copy video URL at current time** to share a link that starts at this moment.
- **Stats for nerds** to see resolution, dropped frames, and buffer health.

## Other useful controls

- Turn off **Autoplay** with the toggle in the player controls so the next video does not start on its own.
- Gear icon > **Subtitles/CC** > **Auto-translate** to read captions in another language.
- Gear icon > **Quality** to lock a resolution and save data.

## Notes

- Option names move between player updates. Look for the same words nearby if you cannot find one.
