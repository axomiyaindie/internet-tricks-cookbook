# YouTube Keyboard Shortcuts

**Purpose:** Control YouTube videos quickly without touching the mouse.
**Requirements:** A desktop browser with the video player focused.

| Key | Action |
|---|---|
| `K` or `Space` | Play or pause |
| `J` / `L` | Rewind or skip forward 10 seconds |
| `Left` / `Right` | Rewind or skip forward 5 seconds |
| `0` to `9` | Jump to 0% to 90% of the video |
| `Home` / `End` | Jump to the start or end |
| `Shift` + `,` / `Shift` + `.` | Decrease or increase playback speed |
| `,` / `.` | Step back or forward one frame while paused |
| `F` | Fullscreen |
| `T` | Theater mode |
| `I` | Miniplayer |
| `M` | Mute |
| `C` | Turn captions on or off |
| `Shift` + `N` / `Shift` + `P` | Next or previous video in a playlist |
| `/` | Focus the search box |
| `?` | Show the full shortcut list |

## Notes

- Shortcuts only work when the page, not a text box, has focus.
- Layout differs slightly on some keyboards, so check the `?` list if one does not work.
