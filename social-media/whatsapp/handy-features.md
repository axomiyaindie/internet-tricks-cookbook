# WhatsApp Handy Features

**Purpose:** Use lesser-known WhatsApp features for notes, search, and organization.
**Requirements:** The WhatsApp app.
**Note:** Menu names change between versions.

| Feature | How |
|---|---|
| Message yourself | New chat > your own name (marked You). Use it for notes and links |
| Star a message | Long-press > Star. Find them in Starred messages |
| Pin chats | Long-press a chat > Pin (up to 3 chats) |
| Pin a message | Long-press a message in a chat > Pin, and choose how long |
| Search by date | Open a chat > search icon > calendar icon |
| Edit a sent message | Long-press within 15 minutes > Edit |
| Keep chats archived | Settings > Chats > Keep chats archived |
| Reply privately in a group | Long-press a group message > Reply privately |
