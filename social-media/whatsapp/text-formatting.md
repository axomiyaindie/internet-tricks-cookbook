# WhatsApp Text Formatting

**Purpose:** Format messages with bold, italics, lists, and code.
**Requirements:** WhatsApp on any device.

Type the characters around your text:

~~~text
*bold*
_italic_
~strikethrough~
```monospace```
`inline code`
> quote
- bullet list item
1. numbered list item
~~~

## Notes

- Do not add spaces between the symbols and the text.
- You can combine styles, for example `*_bold and italic_*`.
- Newer versions also offer formatting buttons when you long-press selected text.
